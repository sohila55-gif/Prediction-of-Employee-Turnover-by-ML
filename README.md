# Prediction-of-Employee-Turnover-by-ML
This repository includes a full workflow for predicting employee turnover. The structure is clear and supports fast understanding for anyone reviewing the project.


Exploratory Data Analysis:


• Monthly hours distribution.

• Number of projects.

• Promotion made in the last 5 years.

• Work accidents.

• Time spent in the company.

• Department comparison.



Data Preprocessing:

• Categorical encoding.

• Min Max scaling.

• Split data into train and test sets.


Model Training:

• Logistic Regression model.

• Random Forest model.

• Hyperparameter tuning.

Model Output:

• Save the final model for future predictions.
